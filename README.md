# Siddhartha Bose — Futuristic Cyber-HUD Portfolio

A production-ready, high-performance developer portfolio built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**. Re-engineered with an original cyber-command-center HUD aesthetic, holographic glass cards, 3D interactive flip timelines, and telemetry diagnostic consoles.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```

---

## 🛠️ Personalization & Centralized Data

All personal and professional information is decoupled from the UI and centralized in:
`src/data/portfolioData.ts`

You can edit:
- **Personal Details**: Name, contact numbers, emails, locations, resume links, bio summaries.
- **Typewriter Titles**: Array of animated hero headlines.
- **Experience**: Companies, roles, durations, and bullet-point achievements.
- **Education**: Degrees, institutions, periods, and 3D flip card highlights.
- **Skills & Diagnostics**: Diagnostic modules with telemetry state badges, percentage progress rings, and logs.
- **Passions & Sports**: Micro-stages for Guitar, Football, Badminton, and Sketching/Anime.
- **Social Links**: LinkedIn, GitHub, Instagram, Telegram, Facebook.

## 🌐 Deploy to Vercel

This repository is pre-configured for zero-config Vercel deployment:
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository and click **Deploy**.
